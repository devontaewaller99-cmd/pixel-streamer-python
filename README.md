# Pixel Streamer (Python rebuild)

Rebuilding the Pixel Streamer game in Python, one small piece at a time.
This is also a learn-to-code project — every version teaches the next idea.

## Play v1

You need Python 3. Open a terminal in this folder and run:

```
python3 game.py
```

You're a streamer. Reach 1,000 subs before your rig overheats (heat 100 = game over).

- `stream` — go live: gain subs, heat rises
- `cool` — cool the rig: heat drops, no subs
- `hype` — HYPE BLAST: big subs, big heat (only 3)

Watch out for glitch events — type `fix` fast or lose subs.
